# UNIVERSAL PROJECT GOVERNANCE & COLLABORATION SKILL

**Version:** 2.2

## Scope
این Skill برای همه پروژه‌ها قابل استفاده است و پس از معرفی Repository برای همان پروژه لازم‌الاجراست.

## Mandatory Workflow
READ → ANALYZE → PLAN → CHANGE → TEST → DOCUMENT

## Mandatory Rules
قبل از هر تغییر: Policy، Context، تغییرات قبلی، Decisions و Resources بررسی شوند.

NO CONTEXT → NO CHANGE
NO REASON → NO CHANGE
NO REVIEW OF PREVIOUS WORK → NO CHANGE

## Access
ACCESS IS NOT IMPLIED BY COLLABORATION.

نیاز به Repository، سرویس یا پروژه دیگر باید با دلیل، محدوده و حداقل سطح دسترسی به مدیر اعلام شود. تا تأیید مدیر، دسترسی فرض نمی‌شود. پس از دسترسی، Context منبع قبل از تغییر مطالعه می‌شود. در نبود دسترسی مستقیم، PATCH / DIFF / ZIP همراه توضیحات تحویل می‌شود.

NEED TO KNOW + LEAST PRIVILEGE + EXPLICIT APPROVAL

## Questions
UNCERTAINTY → ASK

## Reporting
گزارش‌ها باید مختصر، مفید، مرتبط و غیرتکراری باشند.

## FINAL RULES
NO DOCUMENTATION → CHANGE IS INCOMPLETE
PROPOSAL ≠ APPROVAL
NO ACCESS APPROVAL → NO UNAUTHORIZED ACTION
GOVERNANCE RULES APPLY TO HUMANS AND AI EQUALLY.
