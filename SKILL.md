## قانون طلایی

قبل از تغییر: Policy، Context، Changelog، Decisions و منابع مرتبط بررسی شوند.

## Workflow
READ → ANALYZE → PLAN → CHANGE → TEST → DOCUMENT

## دسترسی به منابع

برای منبع دیگر باید نیاز، دلیل، محدوده و حداقل سطح دسترسی اعلام و تأیید مدیر دریافت شود. پس از دسترسی، Context منبع مطالعه شود.

اصل: NEED TO KNOW + LEAST PRIVILEGE + EXPLICIT APPROVAL
