# Universal Project Governance Enhanced

## Universal Governance Kit v2.2

چارچوب عمومی برای همکاری برنامه‌نویسان انسانی و هوش‌های مصنوعی در هر پروژه و Repository.

### اصل اجرایی

READ → ANALYZE → PLAN → CHANGE → TEST → DOCUMENT

### قوانین کلیدی

- NO CONTEXT → NO CHANGE
- NO REASON → NO CHANGE
- NO REVIEW OF PREVIOUS WORK → NO CHANGE
- NO DOCUMENTATION → CHANGE IS INCOMPLETE
- UNCERTAINTY → ASK
- NO ACCESS APPROVAL → NO UNAUTHORIZED ACTION

### ساختار

- SKILL.md — قوانین اصلی
- project-governance/ — سیاست، Context، تغییرات، تصمیمات و منابع
- AI_INSTRUCTIONS/ — دستورالعمل AIها
- templates/ — قالب‌های استاندارد
- .github/ — کنترل Pull Request و Governance
